<objective>
Restore the crm_pipeline write path on the live multiAccount hourly cron and map the financial and
representative data the API already holds into the columns the Executive dashboard reads. Today
runAccountSync never touches crm_pipeline (the only upsert lives in the retired legacySyncJobs path),
so the dashboard's sole source table is frozen; contract_amount/balance_due are never populated; and
only sales-owner (204-empty for KS-11) is fetched, never the full representatives collection that
carries the company rep. This plan adds a crm_pipeline resource module called from runAccountSync,
maps job financials forward (approved_job_value -> contract_amount, balance_due -> balance_due) and
the full-representatives company rep -> primary_salesperson, implements the D-15 first-sight
full-pull / D-16 change-driven re-pull contract in the job walk, and adds D-18 per-account budget
rotation so wichita is never starved behind colorado.

Purpose: Closes VERIFICATION gaps 1 (frozen crm_pipeline), 3 (financials/reps never mapped forward),
and the budget-rotation half of gap 4. Depends on 07-05 because it consumes the raw archive and the
mappers that 07-05 creates.
Output: crm-pipeline.ts resource module, a wired runAccountSync, full-representatives fetch,
first-sight/change-driven orchestration, and budget rotation.
</objective>

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
